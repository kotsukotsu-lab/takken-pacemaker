# 宅建ペースメーカー

試験日まで、今日やる10問だけ。宅地建物取引士試験の**学習記録・復習支援ツール**です。

https://kotsukotsu-lab.github.io/takken-pacemaker/

## これは何か

過去問サイトではありません。**過去問の問題文を持たないこと**が設計の中心にあります。

- 過去問そのものは、一般財団法人不動産適正取引推進機構が公開している公式PDFで読みます
- このサイトが持つのは、年度・問番号・分野・論点・正解番号と、あなたの解答記録だけです
- 一問一答（○×）の問題文と解説は、当方が書き下ろしたものです
- 記録はブラウザの localStorage に保存されます。アカウント登録もサーバーもありません

## 3つのモード

| モード | 中身 | 向いている場面 |
|---|---|---|
| 一問一答 ○× | 自作190問（95論点×2問）。根拠条文つき | 電車・すきま時間。オフラインでも動く |
| 過去問 四択 | 公式PDFを開いて解き、番号だけ入力 | 落ち着いて取り組めるとき |
| 論点セルフチェック | 論点だけ見て思い出せるか確かめる | 2周目以降 |

## このアプリの考え方

**正解＝理解済み、とは扱いません。**

答えるときに自信度を一緒に記録します（確信／二択で迷った／勘）。
「勘で当たった」問題は正解でも段を上げず、明後日また出します。
外した問題は理由（知識不足／読み違え／数字の取り違え）も記録でき、苦手の並べ替えに使います。

復習の間隔は 翌日 → 3日 → 7日 → 30日 → 卒業。

## 収録範囲

令和4年度〜令和7年度の200問。うち令和4年度問48は、国土交通省のデータ改訂により
正解肢のない問題となったため（機構発表）、出題対象から外しています。

論点タグは令和5〜7年度の150問に付いています。令和4年度は未設定です。

## iPhoneで使うとき

**Safariで開いて「ホーム画面に追加」してください。**

Safariのタブのまま長く使わないでいると、保存データが消される仕様（ITP）に当たります。
ホーム画面に追加したWebアプリは別扱いになり、消えにくくなります。
念のため、設定画面から記録の控えを取り出せるようにしてあります。

## 論点タグについて

各問に付いている論点（「二重譲渡／対抗要件・背信的悪意者」など）は、公式の問題文をもとに
**当方で分類したもの**です。機構の著作物ではありません。

## ファイル構成

| ファイル | 中身 | 公開 |
|---|---|---|
| `index.html` | アプリ本体 | する |
| `data.js` | 正解番号・分野・論点・PDFページ・自作190問 | する |
| `sw.js` / `manifest.webmanifest` | オフライン対応 | する |
| `questions.js` | **過去問の問題文**（機構の著作物） | **しない**（.gitignore 済み） |

`questions.js` が隣にあるときだけ、四択の本文が画面に出ます。無ければ公式PDFへのリンクになります。
公開されているのは後者の状態です。

## 非公式であることについて

このサイトは一般財団法人不動産適正取引推進機構とは関係のない非公式のものです。
過去問の問題文そのものは掲載しておらず、同機構の[公式ページ](https://www.retio.or.jp/exam/past_ques_ans/other/)のPDFへリンクしています。
問題文・正解の内容についてのお問い合わせには、同機構・当サイトともにお答えできません。

法改正により、過去の問題が現在の法令と一致しない場合があります。
