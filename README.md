# 宅建ペースメーカー

試験日まで、今日やる10問だけ。宅地建物取引士試験の**学習記録・復習支援ツール**です。

https://kotsukotsu-lab.github.io/takken-pacemaker/

## これは何か

過去問サイトではありません。**問題文を持たないこと**が設計の中心にあります。

- 問題そのものは、一般財団法人不動産適正取引推進機構が公開している公式PDFで読みます
- このサイトが持つのは、年度・問番号・分野・論点・正解番号と、あなたの解答記録だけです
- 記録はブラウザの localStorage に保存されます。アカウント登録もサーバーもありません

## 使い方

1. 今日の10問が自動で組まれます（復習の期日が来た問題が優先されます）
2. 初見の問題は、公式PDFの該当ページを開いて読み、1〜4で答え合わせ
3. 2周目以降は論点だけが表示され、◯（説明できた）／△（あやふや）／✕（思い出せない）で自己採点
4. △✕のときだけ原文リンクが出ます
5. 間違えた問題は翌日 → 3日後 → 7日後と間隔を空けて戻ってきます

## 収録範囲

令和5年度・令和6年度・令和7年度の150問。

## 論点タグについて

各問に付いている論点（「二重譲渡／対抗要件・背信的悪意者」など）は、公式の問題文をもとに
**当方で分類したもの**です。機構の著作物ではありません。

## 非公式であることについて

このサイトは一般財団法人不動産適正取引推進機構とは関係のない非公式のものです。
試験問題そのものは掲載しておらず、同機構の[公式ページ](https://www.retio.or.jp/exam/past_ques_ans/other/)のPDFへリンクしています。
問題文・正解の内容についてのお問い合わせには、同機構・当サイトともにお答えできません。

法改正により、過去の問題が現在の法令と一致しない場合があります。

## 技術

素のHTML/CSS/JavaScript、単一ファイル、外部依存なし。
